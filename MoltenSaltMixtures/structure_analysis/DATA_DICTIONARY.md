# Data dictionary

## `data/4_random_SRO_200ps/random_connectivity_baseline.csv`

Each row describes one composition, first-shell criterion, and M-neighbour
class, where M is Li for LiCl--NaCl and Mg for MgCl2--NaCl.

| Column | Meaning |
|---|---|
| `mixture` | Salt mixture |
| `central_cation` | M species (`Li` or `Mg`) |
| `system` | Trajectory/composition identifier |
| `x_NaCl` | `N_Na / (N_Na + N_M)` |
| `criterion` | `union` for the main figure; `M-Cl` for the control |
| `cutoff_A` | First-shell cutoff in angstrom |
| `mean_cation_degree` | Mean total cation degree of Cl within the cutoff |
| `n_cation_Cl` | Number of M neighbours of Cl (`0`, `1`, `2`, or `3+`); retained as the historical machine-readable column name |
| `P_MD` | Simulated probability of the M-neighbour class |
| `P_MD_block_sd` | Standard deviation of `P_MD` over time blocks |
| `P_random` | Exact hypergeometric random-label probability |
| `delta_P` | `P_MD - P_random` |
| `delta_P_block_sd` | Block standard deviation of `delta_P` |

## `data/4_random_SRO_200ps/cation_cl_rdfs.csv`

Partial M--Cl and Na--Cl radial distribution functions used in panels a and b.
The historical value `X-Cl` in the `pair` column denotes M--Cl.

## `data/4_random_SRO_200ps/warren_cowley_comparison.csv`

Radially resolved Warren--Cowley order used in panels e and f. The historical
column `alpha_XNa` denotes `alpha_MNa`, with M = Li or Mg according to
`central_cation`.

## `data/4_random_SRO_200ps/sro_strength_summary.csv`

Integrated absolute Warren--Cowley order over 3--10 and 6--10 angstrom,
together with block standard deviations and sample counts.

## Earlier-stage directories

- `data/1_MgCl2_RDF/`: partial RDFs and Mg--Cl/Na--Cl first minima.
- `data/2_MgCl2_structure/`: MgCl2--NaCl coordination distributions and
  structural summaries.
- `data/3_Cl_coordination/`: Li--Cl cutoffs and Li/Mg connectivity comparisons.

Each stage includes its own `analysis_metadata.json` when one was generated by
the analysis script.
